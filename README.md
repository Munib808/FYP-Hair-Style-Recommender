# FYP-Hair-Style-Recommender

Hair Style Recommender with Virtual Try-On
Sep 25, 2026 · @Munib
Project Overview
The Hair Style Recommender with Virtual Try-On is an application that helps users discover hairstyles that suit them and preview those styles on their own photo before committing to a change.
Many people hesitate to change their hairstyle because they cannot picture how a new look will actually suit them. This project solves that problem by pairing personalized style recommendations (based on face shape, hair type, and personal preference) with a virtual try-on feature that overlays suggested styles onto the user's own photo in real time.
Key Features
1. Hairstyle Recommendation Engine — suggests suitable hairstyles based on the user's face shape, hair type/texture, and stated preferences (e.g. short/long, casual/formal).
2. Virtual Try-On — lets the user upload or capture a photo and see the recommended hairstyles rendered on their own face before choosing one.
3. Style Gallery & Filters — browse styles by category (e.g. bob, layers, fade) and filter by occasion or maintenance level.
4. Save & Compare — save favorite try-on results and compare them side by side.
5. Share Option — export or share a try-on result, e.g. to send to a stylist for reference.
