# HairSense

## AI Hairstyle and Grooming Recommendation with Virtual Try-On

HairSense is a Final Year Project in the Department of Computer Science. It aims to help users choose suitable hairstyles and grooming styles by combining face-shape analysis with virtual try-on.

Users upload a photo, receive recommendations for hairstyles, beards, mustaches and hair lengths, and preview the suggested styles on their own face. The project comprises a mobile/web application and a salon device prototype, with a tablet/kiosk web application.
